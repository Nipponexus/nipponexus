# データソース調査メモ

## 主要データソース（無料・合法）
1. Wikipedia 日本語版: カテゴリ「日本の祭り」「年中行事」配下
2. Wikipedia 英語版: Category:Festivals_in_Japan
3. Wikidata SPARQL: 構造化データ取得（座標・日付・関連エンティティ）
4. 観光庁オープンデータ: https://www.mlit.go.jp/kankocho/
5. JNTO（日本政府観光局）: https://www.japan.travel/
6. 各自治体観光協会公式サイト: 引用元として出典明記

## 画像ソース
1. Wikimedia Commons: CC-BY-SA / CC0
2. 写真AC: 商用利用可（要クレジット確認）
3. Unsplash: CC0相当
4. 自治体提供フリー素材: 各観光協会の素材ライブラリ

## API制限
- Wikipedia API: 無制限（マナー: User-Agent明記・並列5以下）
- Wikidata SPARQL: 60秒タイムアウト・並列5以下推奨

## 禁忌
- じゃらん・楽天トラベル・るるぶ等の商用サイトのスクレイピング禁止
- Instagram・Twitter等のSNS画像の二次利用禁止
- 出典不明の画像は使用しない
